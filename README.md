# petrochemical-plant-rotating-machinery-dataset
The dataset of rotating machinery from a petrochemical plant includes data from four rotating machines, ranging from normal operation to failure. Each sample is saved in a .txt file.


If you find this resource helpful, please consider to star this repository and cite our research:
G. Zhu, Q. Huang, Q. Zhao, Y. Chen and B. Lin, "A Health Monitoring Index for Rotating Machinery Based on the Logarithmic Interval Quantile Root Mean Square Value Ratio," in IEEE Transactions on Instrumentation and Measurement, doi: 10.1109/TIM.2025.3582313.
